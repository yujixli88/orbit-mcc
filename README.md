🛰 ЦУП · Приложение управления спутником

Прототип приложения Центра управления полётами для хакатона «Код на орбите».

**Проект:** orbit-mcc
**Автор:** Бименде Наргиз Бауржанқызы

Что умеет

- 🌍 Визуализация орбиты: карта с прогнозом траектории и пройденным путём
- 📊 Телеметрия: заряд, температура, скорость, высота, уровень сигнала, топливо
- 🚦 Статусы модулей (питание, связь, двигатель, камера и др.) с цветовой индикацией
- 🎛 Команды оператора: раскрыть батареи, сделать снимок, поднять орбиту, перезагрузить модуль
- ⚠ Случайные и ручные отказы систем для демонстрации

 Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Открыть http://localhost:8000

Технологии

Python, FastAPI, WebSocket · HTML, CSS, JavaScript (canvas)

Как это работает

Симулятор считает орбиту по законам Кеплера (круговая орбита, наклонение 51,6°) и каждую секунду отправляет телеметрию в браузер по WebSocket. Команды оператора уходят на сервер через `POST /api/command`. Заряд батареи и температура зависят от того, на свету спутник или в тени Земли.

## API

| Метод | Адрес | Описание |
|---|---|---|
| WS | `/ws` | поток телеметрии |
| GET | `/api/state` | текущее состояние |
| GET | `/api/track` | прогноз траектории |
| POST | `/api/command` | отправка команды |
